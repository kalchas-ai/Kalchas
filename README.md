## How it works

**Bring anything.** “A competitor just launched at half our price.” “We launch on Hacker News this week.”

**It asks only what it needs.** A few questions about the matter itself, one at a time.

**It builds a world.** Live web intel. People, companies and institutions, each with motives of their own. Blind spots you never saw coming.

**Make your move. Everyone makes theirs.** Watch the dominoes fall. Go back to any decision and try a different timeline.

Live through parallel worlds before you’re stuck with just one.

## Quick start

**With your AI.** Paste this into Claude Code, Codex, Cursor or any coding agent:

```text
Install Kalchas for me and open it: https://github.com/kalchas-ai/Kalchas
Clone the repo, make sure I have Node 22.13+ and pnpm, then run pnpm install.
Copy .env.example to .env.local and ask me for my OpenRouter key (openrouter.ai/keys).
Start it with pnpm start and open http://localhost:3000/app in my browser.
```

**By hand.**

```bash
git clone https://github.com/kalchas-ai/Kalchas.git && cd Kalchas
pnpm install
cp .env.example .env.local   # paste your OpenRouter key
pnpm start                   # open http://localhost:3000/app
```
